# Write an Authentication and Recovery Specification

Define the workflow boundary, actors, authentication factors, session states, recovery rules, permissions, rate limits, notifications, privacy, abuse cases, acceptance criteria, and unresolved policy decisions.

Do not assume a security control exists because it is described in the specification; require code or operational evidence when reviewing an implementation.

# Understand Authentication and Recovery Code

Trace login and recovery entry points to credential checks, MFA, account state, session/token creation, persistence, expiry, revocation, notifications, audit, and downstream authorization.

For each conclusion, capture file/symbol evidence and distinguish authoritative state from cached or derived state.

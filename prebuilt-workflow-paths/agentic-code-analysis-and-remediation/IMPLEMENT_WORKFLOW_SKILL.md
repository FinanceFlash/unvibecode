# Implement Agentic Code Analysis and Automated Remediation Workflow

Confirm:
- Who triggers analysis
- Which repositories are accessible
- Sandbox filesystem boundaries
- Iteration cap and token budget policy
- Command execution approval rules
- Remediation scope and validation
- VCS branch and PR policy
- Credential and secret handling
- Audit retention and privacy
- OWASP LLM01, LLM04, LLM06, and LLM08 controls

Protect:
- Token exhaustion billing
- Excessive agency harm
- Prompt injection compromise
- Sensitive data exfiltration
- Supply chain poisoning
- Sandbox escape
- Unauthorized commits
- Audit evasion

Write implementation steps, People and systems, Things created or changed, Stages, Must not happen, and areas needing verification. Cite files and symbols.

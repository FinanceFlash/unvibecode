# UnvibeCode Contributor and Challenge Credentials

This directory contains public verification records issued by **Alphashots.ai** for recognized UnvibeCode contributors and selected participants in the **UnvibeCode Engineering Challenge 2026**.

Each participant has an individual public credential record in this directory. The credential URL may be added to LinkedIn, a resume, portfolio, or personal website as a verification link.

## LinkedIn Licenses & Certifications

To add your credential on LinkedIn:

1. Open your LinkedIn profile.
2. Select **Add profile section** → **Recommended** → **Add licenses & certifications**.
3. Use the exact award name listed for your name in the table below.
4. Enter **Alphashots.ai** as the issuing organization.
5. Set the issue date to **September 2026**.
6. Leave the expiration date empty.
7. Copy your exact **Credential ID**.
8. Use your personal **Verify** link as the **Credential URL**.
9. Save the certification.

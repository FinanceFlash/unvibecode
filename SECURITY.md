# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public GitHub issue.

Use the repository's **Security** tab and select **Report a vulnerability** to submit a private report. If private vulnerability reporting is not yet enabled, contact the repository owner privately through the maintainer contact listed on the GitHub profile.

Include:

- Affected package version
- A concise description of the vulnerability
- Reproduction steps
- Expected and observed behaviour
- Potential impact
- Any suggested remediation

Do not include real customer source code, production credentials, API keys, or regulated data in the report.

## Scope

Security reports may cover the Python package, CLI, generated local reports, hosted gateway integration, authentication, request handling, or accidental disclosure of repository context.

Reports about usage limits, feature requests, or ordinary runtime errors should be opened as regular issues after sensitive information is removed.
